# トータルリターン定義

本アプリで表示する損益指標の定義。画面ごとに指標が異なる（同名で意味が違う状態を避けるため）。

## 前提となるデータ
- **snapshots**：日付・総資産・含み損益（未実現）・現金。保有証券CSVの取り込みで作成
- **realized_pnl**：売却の実現損益（税引前）＋約定日。実現損益CSVの取り込み
- **dividends**：受取配当（税引後）＋受渡日。配当CSVの取り込み
- 入出金履歴（純入金額）・買付履歴・取り込み範囲外/スナップショット開始前のデータは**持っていない**

## 1. 年間トータルリターン（portfolio ページ）
「今年の運用成果」。

```
年間トータルリターン ＝ 当年の実現損益 ＋ 当年の受取配当（税引後） ＋ 現在の含み損益（全額）
```

- 当年 ＝ 暦年（1/1〜現在）。実現は約定日、配当は受渡日で判定
- **割り切り**：前年末の含み損益（年末スナップショット）が取れないため、含み増減ではなく**現在の含みを全額**加算する。よって年初から持ち越した含み分だけ**上振れ**する
- 実装：`annualReturn()`（`frontend/src/lib/totalReturn.ts`）

## 2. 生涯トータルリターン（history ページ）
「投資活動全体の総成果」。

```
生涯トータルリターン ＝ 通算の実現損益 ＋ 通算の受取配当（税引後） ＋ 現在の含み損益
```

- **「通算」＝取り込み開始以降**（取り込んでいない過去分は含まない）
- 実装：`lifetimeTotals()` ＋ 現在含み（portfolioStore）
- 参考（純資産ベース：`現在の評価総額 − 通算純入金額`）は**入出金履歴が無いため算出不可**。概念メモに留める

## 3. 各年のトータルリターン履歴（history ページ・年次テーブル）

```
過去年：トータルリターン ＝ その年の実現損益 ＋ その年の受取配当   （含みなし）
当年　：トータルリターン ＝ 当年の実現損益 ＋ 当年の受取配当 ＋ 現在の含み損益
```

- 過去年に含みを入れないのは、各年末の含み（＝前年末基準）が取れないため
- 実装：`yearlySummary(..., currentUnrealized)`。当年行のみ `unrealized` を反映

## 整合
```
生涯トータルリターン
  ＝ 通算実現 ＋ 通算配当 ＋ 現在含み
  ＝ Σ(過去年の実現＋配当) ＋ (当年の実現＋配当＋現在含み)
  ＝ Σ(過去年のトータルリターン) ＋ 今年の年間トータルリターン
```

## グラフ（history ページ・推移グラフ②）
「累計損益の推移」は各スナップショット日時点で `含み(t) ＋ Σ実現(≤t) ＋ Σ配当(≤t)`（`cumulativeBreakdownByDate`）。右端 ≒ 生涯トータルリターン（最新スナップショットより後の実現・配当があるとわずかにズレる）。
